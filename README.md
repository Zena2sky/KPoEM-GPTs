# KPoEM_GPTs

이 리포지터리는 전자책 『디지털인문학 연구를 위한 고급 자연어처리 활용』의 「06. 파인튜닝/RAG 없이 쉽게 활용하는 GPTs」 파트를 보완하는 자료 저장소입니다.

---

## 📚 리포지터리 목적

전자책에서 다루기 어려운 **프롬프트 구조** 를 공유하여  
관심 있는 연구자가 라벨드 데이터 GPTs 제작 과정을 이해하고 확장해 나갈 수 있도록 돕는 것을 목표로 합니다.

---

## 📁 데이터 소개

본 리포지터리에서 사용한 데이터는 **한국 현대시 기반 감정 라벨링 데이터**입니다.  
- 김소월, 윤동주, 임화, 이상, 한용운 등 주요 시인의 작품 총 483편  
- 7,007개 행별 문장 + 5인의 어노테이터가 44개 감정 라벨 중 최대 10개 감정 라벨링  
- GPTs에 지식파일로 제공한 최종 학습용 데이터는 3인 이상 공통 동의 감정만 추출한 것 

데이터 원본: [Zenodo 링크](https://zenodo.org/records/15572285)
